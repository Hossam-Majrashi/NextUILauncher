2. DETAILED TECHNICAL BOTTLENECKS & REMEDIATION PLAN
================================================================================

### A. Icon Loading, Memory Management & Bitmaps
- [Issue]: Loading PNG BLOBs from SQLite and decoding on the main/IO thread during swipes causes micro-stutters.
- [Fix]: Migrate to pre-scaled HardwareBitmaps in L1 LRU memory cache + fast asynchronous file-based disk cache.
- [Fix]: Reduce memory allocations by reusing Bitmap options (`inBitmap` / DirectBuffers) and dynamic memory limits.
- [Fix]: Preload upcoming pages before the user reaches them based on scroll direction and velocity.
- [Fix]: Eliminate per-cell `animateFloatAsState` alpha transitions during scroll flings.

### B. Compose Recomposition & Cell Bloat
- [Issue]: Each `AppCell` holds 4+ mutable state variables and instantiates `DropdownMenu` and dialogs inside the grid.
- [Fix]: Make `AppCell` completely stateless and immutable. Hoist menu and dialog states to the root `LauncherScreen`.
- [Fix]: Replace standard `List<T>` with `ImmutableList<T>` to enable Compose Compiler Smart Skipping.

### C. Rapid Page Navigation & Scroll Physics
- [Issue]: Scrubbing bar gesture detector spams `pagerState.scrollToPage()` continuously, stalling the UI thread.
- [Fix]: Throttle scrubbing events; use instantaneous non-animated positioning during active drag and smooth settle 
         on release.
- [Fix]: Remove the main thread busy-wait loop `while (pagerState.isScrollInProgress) delay(16)`.

### D. ViewModel Reactive State Computation
- [Issue]: Monolithic `LauncherUiState` rebuilds on every search keypress or pin toggle, triggering full re-renders.
- [Fix]: Decouple into granular reactive flows (`drawerState`, `homeState`, `searchState`, `dialogState`).
- [Fix]: Run `rebuildStateSync` computations strictly on `Dispatchers.Default`.
